Auth routes are protected against brute-force with express-rate-limit: 20 requests per 15 minutes.

Input Validation
All inputs are sanitized and validated server-side with express-validator before hitting the database.

Secure Cookies
Tokens stored as httpOnly, Strict SameSite cookies alongside localStorage for flexibility.

Protected Routes
Dashboard requires a valid JWT. Unauthenticated users are automatically redirected to login.

Role-Based Access
User roles (user/admin) are stored in the DB and embedded in the JWT for future RBAC expansion.
